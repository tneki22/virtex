# Virtex

Локальный тренажер для подготовки к экзамену по базам данных. Приложение открывает основной экзамен сразу с маршрута `/`, поддерживает режим изучения, пробный экзамен, заметки, голосовой ввод и AI-проверку ответов через OpenRouter или GroqCloud.

## Запуск

Требуется Node.js 22.12 или новее и npm 10 или новее.

```powershell
npm ci
npm run app
```

После запуска откройте `http://127.0.0.1:4173`.

Для разработки с автоматической перезагрузкой:

```powershell
npm run dev
```

## Материалы к экзамену

Файлы для раздела "Материалы к экзамену" лежат в папке `materials/` в корне проекта. Сервер читает эту папку динамически: если добавить, удалить или заменить файл, список на странице экзамена обновится без правок в React-коде.

Поддерживаются любые типы файлов. По нажатию на материал браузер открывает файл по адресу `/materials/<имя-файла>` или скачивает его, если формат не поддерживается для просмотра.

## Настройка AI

Скопируйте `.env.example` в `.env` и укажите ключ OpenRouter или GroqCloud. Провайдера, модель текста, модель распознавания речи и режим streaming для tutor-чата можно выбрать в интерфейсе приложения.

Runtime-настройки сохраняются в локальной SQLite базе `runtime/virtex.sqlite`. API-ключи не возвращаются браузеру.


```powershell
npm run test:e2e
```

Если на `5173` уже запущен dev server с другим окружением, запускайте Playwright изолированно:

```powershell
$env:E2E_PORT='5174'; $env:E2E_REUSE_SERVER='false'; npm run test:e2e
```
