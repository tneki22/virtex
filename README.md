# Virtex

Локальный тренажёр для подготовки к экзаменам. Поддерживает режим изучения, пробные экзамены, заметки, голосовой ввод и AI-проверку ответов через OpenRouter или GroqCloud.

## Запуск

Требуется Node.js 22.12 или новее и npm 10 или новее.

```powershell
npm ci
npm run app
```

После запуска откройте `http://127.0.0.1:4173`.

Для разработки с автоматической перезагрузкой:

```powershell
npm run dev
```

## Настройка AI

AI-функции необязательны. Без API-ключа доступны вопросы, эталонные ответы, заметки и локальные черновики.

Скопируйте `.env.example` в `.env` и укажите ключ OpenRouter или GroqCloud. Провайдера и модели можно выбрать в интерфейсе приложения. Локальные данные сохраняются в `runtime/virtex.sqlite` и не попадают в Git.
