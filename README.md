# Virtex

Локальный тренажёр подготовки к экзаменам. В комплекте находится пакет из 48 вопросов по базам данных, эталонные ответы из `detailed_answers.pdf`, AI-проверка через OpenRouter и голосовой ввод через Groq Whisper.

## Быстрый запуск

Требуется Node.js 22.12 или новее.

```powershell
npm ci
npm run app
```

После сообщения о запуске откройте `http://127.0.0.1:4173`. Данные подготовки сохраняются локально в `runtime/virtex.sqlite`.

Для разработки с автоматическим обновлением клиента и сервера:

```powershell
npm run dev
```

## AI-проверка

Сервер читает `.env` и `.env.local`; ключ никогда не передаётся браузеру. Локальный `.env` уже исключён из Git. Пример конфигурации:

```dotenv
OPENAI_BASE_URL=https://openrouter.ai/api/v1
OPENAI_API_KEY=your-key
OPENAI_MODEL=openai/gpt-5-mini
GROQ_API_KEY=
GROQ_BASE_URL=https://api.groq.com/openai/v1
GROQ_WHISPER_MODEL=whisper-large-v3-turbo
VIRTEX_DATA_DIR=./runtime
```

Страница «Настройки» отдельно показывает готовность AI-проверки и голосового ввода. Соединение AI можно проверить без раскрытия ключа. Без ключа проверки доступны эталоны, заметки, закладки и локальные черновики, но числовая оценка не выставляется.

Голосовая запись начинается только после нажатия «Диктовать». Аудио передаётся сервером в Groq, не сохраняется в SQLite и после транскрипции освобождается из памяти. Распознанный текст добавляется в черновик и может быть исправлен до отправки ответа.

## Режимы

- «Изучение»: ручной выбор вопроса, эталон и заметки доступны сразу.
- «Экзамен»: 1, 2, 3 или 5 случайных вопросов без повторов; эталон закрыт до итоговой проверки каждого ответа.

В обоих режимах AI может задать не более двух уточнений. Диалог продолжается внутри текущего вопроса без повторного запуска сессии.

## Новый экзамен

Пакеты находятся в `content/exams/<exam-id>`. Runtime работает только с проверенным `compiled/package.json`; полный документ модели не отправляется. Подробный формат и порядок подключения описаны в [docs/ADDING_EXAMS.md](docs/ADDING_EXAMS.md).

## Структура

- `client/` — React-интерфейс.
- `server/` — Express API, SQLite и AI-адаптер.
- `shared/` — контракты и схемы Zod.
- `content/` — исходные и скомпилированные экзаменационные пакеты.
- `scripts/` — компилятор, подготовка контента и калибровка промпта.
- `tests/` — unit, контрактные, контентные и E2E-тесты.
