# Интерактивный тренажер: Экзамен по Базам Данных (МГТУ им. Н.Э. Баумана)

Добро пожаловать в проект интерактивного тренажера-симулятора сдачи экзамена по курсу "Системы управления базами данных" (СУБД / НБД). Данный проект создается как умный, геймифицированный учебный ассистент, который позволяет проверять теоретические знания студента, используя как методы классических ИИ-агентов (LLM), так и встроенную ручную локальную проверку.

## Описание логики проекта (Как это работает)

Основная идея проекта — симулировать процесс сдачи экзамена преподавателю или прохождения технического собеседования.

Проект состоит из **трёх смысловых панелей (3-pane layout)**:
1. **Левая панель (Оглавление и Геймификация):** Здесь студент видит список модулей (например, "Архитектура", "Транзакции", "Индексы") и конкретные вопросы (билеты). За успешные ответы студент получает очки опыта (XP), прогресс сохраняется локально.
2. **Центральная панель (Чат с Экзаменатором):** Поле для ввода ответа на выбранный билет. Студент может выбрать "личность" экзаменатора (Personality), что кардинально меняет логику и тон проверки:
   * **Строгий преподаватель (Фомин М.М.):** Академический и фундаментальный стиль, требующий идеального знания терминов, сухие оценки.
   * **Senior DBA (Кейсы):** Строгий технический интервьюер. Проверяет знания через призму реальных "аварийных" ситуаций на продакшене.
   * **Junior Mentor:** Добрый наставник, объясняющий абстрактные концепции СУБД на простых примерах (пицца, доставка,...).
3. **Правая панель (Учебник):** Встроенная читалка  которая открывает официальную методичку и автоматически синхронизируется с выбранным билетом, позволяя быстро подсмотреть правильный ответ (конспект) прямо во время подготовки.

### Под капотом (Server-side & AI Logic)
* **Backend :** При старте сервера  система ищет в  `файлы учебников (в частности, `Подготовка к экзамену НБД.pdf`). С помощью библиотеки `pdf-parse` бэкенд "читает" весь учебник и сохраняет его текст в память.
* **LLM Интеграция:** Когда студент отправляет свой ответ, бэкенд комбинирует *личность экзаменатора, весь извлеченный текст учебника и ответ студента*, после чего отправляет запрос в LLM (по умолчанию используется OpenRouter с моделью `deepseek/deepseek-v4-pro`). LLM возвращает JSON с текстом лекции/комментария, баллами `score_delta`, цитатой из учебника и массивом пропущенных терминов.
* **Local Fallback:** Если API ключ не задан или нейросеть недоступна, срабатывает локальный алгоритм в `server.ts`. Он берёт ожидаемые `keywords` (ключевые слова) из базы вопросов и просто сравнивает их с текстом ответа, выдавая баллы в зависимости от того, какой процент ключей был угадан.

## Стек технологий (предлагается но это не точно...)

*   **Frontend:** React 19, TypeScript, Tailwind CSS, Zustand (хранение стейта), Lucide React (иконки).
*   **Backend:** Express, Node.js + tsx + esbuild для эффективной сборки в единый файл без утечек модулей. Виртуальный сервер Vite работает как миддлвар для удобного дев-режима.
*   **Чтение PDF:** Клиент — динамическая загрузка скрипта `pdf.js` из CDN. Сервер — `pdf-parse`.
*   **AI:** `openai` SDK, настроенный на endpoint OpenRouter.

## Запуск проекта

1. Установите зависимости: `npm install`
2. Настройте ключи в `.env` по примеру `.env.example` (Вам понадобится `OPENROUTER_API_KEY`, если хотите использовать ИИ оценку).
3. Запустите в среде разработки с HMR: `npm run dev`
4. Для сборки в production: `npm run build` -> `npm start`
