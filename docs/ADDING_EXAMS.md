# Добавление экзамена

Новый экзамен подключается разработчиком как каталог `content/exams/<exam-id>`. Это намеренное ограничение первой версии: пользовательские документы не загружаются в runtime без предварительной проверки.

## Состав пакета

```text
content/exams/example/
  manifest.json
  questions.json
  style-guide.md
  documents/
    source.pdf
```

`manifest.json` задаёт ID и версию пакета, название, предмет, профили экзаменатора, документы, пороги готовности и правила экзамена. `questions.json` содержит независимые вопросы с официальной и отображаемой формулировками, эталоном, акцентами и ссылками на страницы или фрагменты источников.

## Обязательные правила

- ID пакета, вопросов и документов уникальны и стабильны между версиями.
- Каждый вопрос содержит отдельный эталонный ответ.
- Каждая ссылка указывает на существующий документ и страницу.
- Цитаты должны подтверждаться извлечённым текстом документа.
- Вопросы с одинаковой темой остаются независимыми, если в официальном списке у них разные номера.
- Исправленная формулировка хранится в `displayText`, исходная — в `officialText`.
- `style-guide.md` должен быть коротким: он входит в каждый AI-запрос.

## Компиляция

Для нового пакета запустите компилятор напрямую:

```powershell
npx tsx scripts/compile-exam.ts content/exams/example
```

Проверка без перезаписи результата:

```powershell
npx tsx scripts/compile-exam.ts content/exams/example --check
```

Компилятор извлекает текст, формирует fragment ID, проверяет документы, страницы, ссылки, ID и эталоны. При ошибке пакет не публикуется. После успешной компиляции перезапустите сервер: он автоматически обнаруживает все каталоги с `compiled/package.json`.

## AI и калибровка

На один ход сервер передаёт модели только текущий вопрос, эталон, связанные фрагменты, краткие правила, профиль экзаменатора и текущий диалог. Контекст ограничен, а ссылки в ответе модели проверяются против реально переданных фрагментов.

Перед использованием баллов нового экзамена как показателя готовности добавьте `calibration.json` с фиксированными полным, частичным, ошибочным, пустым, неподтверждённым и инъекционным ответами. Затем выполните:

```powershell
npx tsx scripts/calibrate-prompt.ts content/exams/example
```

Скорректируйте эталоны, акценты и промпт, если результаты выходят за ожидаемые диапазоны.
